# Transaction Anomaly Detection Pipeline — Technical Design & Results

**Space:** CR | **Date:** 2026-04-16 | **Author:** heramb | **Status:** Published

---

## 1. Executive Summary

This document describes the end-to-end ML pipeline built to detect anomalous (fraudulent) financial transactions using a combination of unsupervised (Isolation Forest) and supervised (XGBoost) machine learning models. The pipeline processes 10,000 synthetic transactions with a 5% anomaly rate and achieves XGBoost ROC-AUC = 1.0 on held-out test data. A FastAPI inference service exposes the model for real-time single and batch predictions.

**Key outcomes:**
- 39 unit tests + 10 Playwright e2e tests — all passing
- 12/12 data validation checks pass
- XGBoost: F1=1.0, AUC=1.0 | Isolation Forest: F1=0.64, AUC=0.986
- FastAPI with 5 endpoints, every response includes `request_id` + `timestamp`
- Full JIRA Epic (ADP-8) with Sprint 1 tracking 6 stories

## 3. Data Description

### Source
Synthetic dataset generated by `scripts/generate_data.py` using NumPy (seed=42).

| Attribute | Value |
|-----------|-------|
| Total rows | 10,000 |
| Normal transactions | 9,500 (95%) |
| Anomalous transactions | 500 (5%) |
| Features (raw) | 13 columns |
| Date range | 2024-01-01 to ~2024-05-26 |

### Schema

| Column | Type | Description |
|--------|------|-------------|
| transaction_id | string | Unique transaction identifier |
| timestamp | datetime | Transaction timestamp |
| amount | float | Transaction amount (USD) |
| merchant_category | string | grocery / gas / restaurant / retail / online / travel |
| card_present | bool | Physical card used |
| country_code | string | 2-letter ISO country code |
| hour_of_day | int | 0–23 |
| day_of_week | int | 0 (Mon) – 6 (Sun) |
| customer_id | int | Customer identifier |
| merchant_id | int | Merchant identifier |
| num_prev_txn_1h | int | Prior transactions in last hour |
| distance_from_home_km | float | Distance from home location |
| is_anomaly | int | Label: 0=normal, 1=anomaly |

### Fraud Attack Patterns

| Pattern | Amount Range | Indicator |
|---------|-------------|-----------|
| Large-amount fraud | $5,000–$25,000 | High amount at night |
| Micro card-testing | $0.01–$0.99 | Very small amounts |
| Card-not-present spike | $500–$1,500 | card_present=False |
| Rapid sequential | $200–$800 | num_prev_txn_1h ≥ 8 |
| Foreign unusual | $1,000–$4,000 | Non-US country code |

## 5. Feature Engineering

`src/features.py` produces **21 new features** beyond the 13 original columns:

### Time Features (cyclical encoding)
| Feature | Formula | Purpose |
|---------|---------|---------|
| hour_sin | sin(2π × hour/24) | Cyclical hour encoding |
| hour_cos | cos(2π × hour/24) | Cyclical hour encoding |
| dow_sin | sin(2π × dow/7) | Cyclical day-of-week |
| dow_cos | cos(2π × dow/7) | Cyclical day-of-week |
| is_business_hours | hour ∈ [9, 17] | Business hours flag |
| month | timestamp.month | Calendar month |

### Statistical Features
| Feature | Formula | Purpose |
|---------|---------|---------|
| amount_zscore | (log_amount − μ) / σ | Normalised amount deviation |
| amount_log_ratio | log_amount / median | Relative amount size |
| amount_squared_log | log_amount² | Non-linear amount signal |

### Velocity Features (per customer)
| Feature | Aggregation | Purpose |
|---------|------------|---------|
| customer_txn_count | count | Transaction frequency |
| customer_avg_amount | mean | Spending baseline |
| customer_amount_std | std | Spending variability |
| customer_max_amount | max | Highest historical spend |
| amount_vs_customer_avg | amount / avg | Deviation from personal norm |

### Categorical Features
- 6 merchant category dummy columns (cat_grocery, cat_gas, etc.)
- merchant_risk_score: online/travel=3, retail=2, grocery/gas/restaurant=1

## 6. Model Training

### Isolation Forest (Unsupervised)

```python
IsolationForest(
    n_estimators=200,
    contamination=0.05,
    random_state=42,
    n_jobs=-1,
)
```

Trained on StandardScaler-normalised features. Anomaly score = negated decision function.

### XGBoost (Supervised)

```python
XGBClassifier(
    n_estimators=300,
    max_depth=6,
    learning_rate=0.05,
    subsample=0.8,
    colsample_bytree=0.8,
    scale_pos_weight=19.0,   # handles 19:1 class imbalance
    eval_metric="aucpr",
    random_state=42,
)
```

### Results (80/20 stratified split, 2,000 test samples)

| Model | Accuracy | Precision | Recall | F1 | ROC-AUC | Avg Precision |
|-------|----------|-----------|--------|----|---------|----------------|
| XGBoost | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 1.0000 |
| Isolation Forest | 0.9840 | 0.5580 | 0.7400 | 0.6364 | 0.9861 | 0.6840 |
